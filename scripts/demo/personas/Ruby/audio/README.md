# Ruby 音訊庫使用說明

## 目錄結構

```
personas/Ruby/audio/
├── 早安/        # 標籤 {audio_早安}
├── 午安/        # 標籤 {audio_午安}
├── 晚安/        # 標籤 {audio_晚安}
├── 笑聲/        # 標籤 {audio_笑聲}
├── 撒嬌/        # 標籤 {audio_撒嬌}
└── 應答/        # 標籤 {audio_應答}
```

## 怎麼用

把音檔丟進對應分類資料夾，檔名隨意。

例：
```
早安/
├── 01.m4a    # Ruby 說「早安啊」（女聲，台北口音）
├── 02.m4a    # Ruby 說「早安~ 你也好早」
└── 03.m4a    # Ruby 說「噗 你今天好早起」
```

Claude 在 reply 內若出現 `{audio_早安}` 標籤 → 系統會**從早安資料夾隨機抽一個**音檔發送。

## 支援格式

m4a / mp3 / wav（LINE 桌機都會偵測為音訊，對方端看到「▶ 00:0X」語音氣泡）

## 怎麼觸發

在 Ruby/persona.txt 內提示 Claude 適合時機可用 `{audio_早安}` 之類標籤回覆。

例：
```
規則 X：偶爾發語音訊息加真實感
- 早安問候時，可回 `{audio_早安}` 而不是打字
- 大笑情境可回 `{audio_笑聲}`
- 撒嬌可回 `{audio_撒嬌}`
- 節制：每天最多 1-2 條語音，不要連發
```

## 技術細節

- 用 win32 WM_DROPFILES 模擬拖拉檔案到 LINE 對話框
- LINE 接收後自動跳「傳送檔案」對話框
- 程式按 Enter 確認傳送
- 對方端收到 = 語音訊息氣泡（跟手機錄音無法區分）

## 加新分類

要加新分類（例如「碎念」）：
1. 在這目錄底下建 `碎念/` 資料夾
2. 丟音檔進去
3. Claude reply 用 `{audio_碎念}` 標籤自動觸發

不用改 code。
